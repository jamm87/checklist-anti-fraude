# Checklist antifraude (España)

Web estática, sin dependencias, sin cookies, sin analítica y sin formularios.

- `index.html`: guía completa (7 pasos, siguiente nivel, qué hacer si algo sale mal).
- `imprimir.html`: hoja A4 para imprimir y rellenar a mano (3 páginas). No tiene campos de entrada: nada se guarda en el dispositivo.
- `styles.css`: estilos compartidos, modo oscuro y estilos de impresión.

Publicar: sirve la carpeta tal cual (GitHub Pages, Netlify, Cloudflare Pages…). Para probar en local: `python3 -m http.server`.

Fuente: checklist original de Erica Brescia (Redpoint), adaptado a España en https://x.com/mike_arias/status/2122958905756004706
